# HackIllinois Schedule

An ocean-themed schedule page built for the HackIllinois 2027 Systems Team coding challenge.

The site fetches event data from the HackIllinois API and allows users to browse events by day and view additional information about each event.

## Features

- Live event data from the HackIllinois API
- Friday, Saturday, and Sunday schedule filtering
- Chronologically sorted events
- Clickable event cards with event details
- Responsive ocean-themed interface

## Built With

- React
- TypeScript
- Vite
- Recoat Deep Ocean
- Three.js

## Sources

- [HackIllinois Adonix API](https://adonix.hackillinois.org/docs/) - Event data
- [Recoat Deep Ocean](https://recoat.dev/backgrounds/deep-ocean) - Animated ocean background
- [Three.js](https://threejs.org/) - 3D rendering dependency used by the background
- ChatGPT - Used for assistance with React/TypeScript concepts, debugging, and UI development
